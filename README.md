# asia_web
# 🚀 Портфоліо проєктів: Веб-технології та веб-дизайн

Цей репозиторій містить колекцію веб-додатків та сторінок, розроблених під час вивчення сучасних веб-технологій. Головна мета — демонстрація навичок від базової верстки до роботи з API та реактивним програмуванням.

## 📂 Структура проєктів

* **Лабораторні 1-4 - Портфоліо:** Основи HTML та CSS, семантична та адаптивна верстка, дизайн статичних сторінок.
* **Лабораторні 5-6 - Book Finder:** Інтерактивний додаток для пошуку книг. Робота з JavaScript, маніпуляції з DOM та налаштування асинхронних запитів (Fetch) до зовнішніх API.
* **Лабораторна 7 - Reactive Todo List:** Сучасний список завдань, розроблений із використанням реактивної бібліотеки RxJS для управління станом та подіями.
* **Лабораторні 8-9 - Portfolio SPA (Vue 3):** Сучасний односторінковий додаток на Vue 3 та Vite. Реалізовано компонентну архітектуру, багатомовність (UK/EN), темну тему, Todo List з фільтрацією та інтеграцію з OpenWeatherMap API для отримання поточної погоди.
* **Лабораторна 10 - CI/CD Automation & E2E Testing:** Налаштування безперервної інтеграції та розгортання (CI/CD) за допомогою GitHub Actions. Реалізовано End-to-End (E2E) тестування, кросбраузерні перевірки та написання YAML-конфігурацій для автоматичного деплою додатку.

## 🛠 Технологічний стек

* **Мови:** HTML5, CSS3, JavaScript (ES6+), TypeScript, Vue.js
* **Бібліотеки та інструменти:** RxJS, GitHub Actions, E2E Testing
* **Інше:** Git, GitHub Pages, маніпуляції з DOM, REST API,CI/CD Pipelines, YAML
